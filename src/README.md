# Source

The working system. One package per functional feature, so that the module
boundaries stay visible in the directory layout.

| Package | Functional feature |
| --- | --- |
| `nlu/` | Natural-language question parsing |
| `retrieval/` | Trajectory retrieval and filtering |
| `visualization/` | Chart type selection and rendering |
| `summary/` | Plain-language summary of a result |
| `evaluation/` | Benchmark run and metric dashboard |
| `export/` | Export of figure plus intermediate artefacts |

Empty until implementation starts.
