# TrajVis Studio

A self-service platform that turns plain-language questions about moving-object
data into trajectory visualizations, so that analysts who do not write query
languages can explore a trajectory dataset on their own.

Course project for **Software Engineering** — Macau University of Science and
Technology. Group 1, team *泓泓说的都队*.

## What the system does

1. Parse a natural-language question into a structured visualization specification.
2. Retrieve and filter the trajectories that the question refers to.
3. Choose the appropriate chart type and render it automatically.
4. Summarize the result in plain language.
5. Measure the whole pipeline against a benchmark and show the outcome in a dashboard.
6. Export the figure together with every intermediate artefact, so a result can be reproduced.
